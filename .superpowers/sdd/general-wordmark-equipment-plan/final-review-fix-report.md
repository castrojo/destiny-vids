## Fixes

### 1. Explicit ensemble uploads

`scripts/build_uta_ensemble.py` no longer uploads the obsolete
`/work/ens-t*.jpg` path. The full-mode upload loop now contains explicit paths
for every workflow-produced artifact:

- the final master and probe/gate records;
- the frame plan and review hashes;
- each named `review-*.jpg` output after the workflow's rename step;
- each keyed-child proof generated by `key_step`.

`tests/test_uta_ensemble.py::test_full_upload_loop_contains_only_workflow_outputs`
extracts the generated full upload loop, compares it with the complete
workflow-produced path set, rejects wildcard paths, and proves the legacy
`ens-t*.jpg` glob is absent.

### 2. Remote true-peak delivery gate

The existing remote `ebur128=peak=true` measurement remains the only audio
measurement step. The workflow now parses the final `True peak` summary from
`/work/ens-ebur128.txt`, records the numeric value as
`true_peak_dbtp=<number>` in `/work/ens-gates.txt`, and fails under `set -e`
when the value is missing, malformed, or greater than or equal to `0 dBTP`.

The artist mix is unchanged: the same source, static gain, single AAC encode,
and no normalization or EQ remain in the workflow. The focused manifest tests
cover both the summary parser and the `>= 0 dBTP` failure condition.

### 3. Hero stream-contract documentation

`docs/skills/hero-videos/SKILL.md` now distinguishes workflow classes:

- video-only picture workflows require exactly one video stream and no audio;
- ensemble and final mux workflows require exactly one video stream and one
  audio stream.

The documentation remains current-state guidance and contains no version
narrative.
